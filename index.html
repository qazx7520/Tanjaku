    ⚙️ 실시간 연결 설정

    여러 학생의 휴대폰과 교사용 화면을 동기화하려면 Firebase Realtime Database를 사용합니다. 무료 Spark 요금제로 시작할 수 있습니다.

    중요: HTML 파일만 올리면 서로 다른 기기의 소원이 자동으로 공유되지는 않습니다. 아래 Firebase 프로젝트 설정이 필요합니다. 연결 전에는 이 브라우저에서만 작동하는 체험 모드입니다.
    연결 설정을 저장하면 자동으로 동기화합니다.
    Firebase 연결 방법 (교사용)
    1. Firebase Console에서 프로젝트를 만듭니다.
    2. 웹 앱을 추가하고 앱 설정의 JSON 객체를 복사합니다.
    3. 빌드 → Realtime Database를 생성하고 databaseURL을 확인합니다.
    4. 아래 예시 규칙은 공개 참여 수업용입니다. 학생 이름 등 개인정보를 받지 않는 것을 권장합니다. 운영 후 데이터베이스를 삭제하거나 규칙을 닫으세요.
    5. 학생들이 설정 화면을 보지 않게 하려면 교사용 비밀번호/인증이 있는 별도 백엔드가 필요합니다. 이 파일은 간편한 수업 시연용이며 보안이 강화된 관리 시스템은 아닙니다. 학생이 제출한 소원 삭제는 Firebase 콘솔에서 직접 진행하세요.

    안전한 데이터베이스 규칙은 파일과 함께 제공된 안내를 참고하세요.

    주의: 아래 안내의 추가 전용 규칙을 Firebase 콘솔에 설정하세요. 화면의 삭제 버튼은 해당 규칙에서는 작동하지 않으며 Firebase 콘솔에서 삭제해야 합니다.
